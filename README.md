# TiSpetta

Scopri in 1 minuto quali bandi e agevolazioni pubbliche può chiedere la tua impresa.

- Sito: https://ada253.github.io/tispetta/
- Bandi: `bandi.js` (aggiorna `verificato` quando ricontrolli una scheda)
- Database: tabelle `ts_*` nel progetto Supabase "hairagione" (`supabase.sql`)
- Richieste di aiuto da gestire: vista `ts_richieste_da_gestire` nel pannello Supabase
